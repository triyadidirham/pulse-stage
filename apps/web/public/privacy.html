VERSI PENGEMBANGAN

Anda mengendalikan data Anda.

PulseStage membagikan detak jantung ke overlay siaran hanya setelah Anda menghubungkan jam dan menekan Start. Streaming memakai sesi aktivitas Wear OS melalui Health Services, hanya meminta BPM tanpa GPS. Hentikan sesi olahraga aplikasi lain sebelum Start. Tekan Stop untuk mengakhiri pembacaan dan pengiriman.

Data yang digunakan

Server menerima BPM, waktu pembacaan, dan pengenal perangkat acak. Nama pemain dan hash kredensial pairing disimpan untuk menghubungkan perangkat. Kredensial asli disimpan pada jam dan browser pengelola. Cadangan aplikasi jam dinonaktifkan.

Siapa yang dapat melihat?

Siapa pun yang memiliki tautan overlay dapat melihat BPM saat sesi aktif. Jika overlay ditayangkan melalui OBS, penonton siaran juga dapat melihatnya. Kode pairing di jam memberi akses pengelolaan dan dapat dipakai kembali di browser lain. Kode pairing dan tautan OBS tidak kedaluwarsa. Ganti tautan OBS dari dashboard untuk mencabut seluruh tautan overlay lama. Jika kode pairing bocor, tekan Reset kode akses di jam untuk mencabut kode beserta semua akses browser dan tautan OBS lama.

Penyimpanan dan penghapusan

Server tidak menyimpan riwayat BPM ke database. Pembacaan terakhir hanya berada di memori, tidak ditampilkan setelah kedaluwarsa, dan dibuang dalam sekitar 65 detik atau saat sesi berhenti. Registrasi dan hash kredensial disimpan hingga Anda menghapus koneksi. Pilih Hapus pairing di web atau Hapus koneksi di jam untuk menghapus registrasi perangkat dari database aktif. Reset kode akses mengganti kode dan mencabut akses lama, tetapi mempertahankan registrasi jam. Penghapusan dari cadangan server mengikuti kebijakan operator saat layanan produksi diluncurkan.

Tentang versi ini

Ini adalah penjelasan perilaku prototipe lokal, belum merupakan kebijakan layanan publik final. Sebelum publikasi, operator layanan harus mencantumkan identitas, kontak privasi, wilayah hosting, serta periode penyimpanan log dan cadangan yang sebenarnya. Tidak ada analitik atau iklan pihak ketiga dalam prototipe ini.
