VERSI PENGEMBANGAN

Anda mengendalikan data Anda.

PulseStage membagikan detak jantung ke overlay siaran hanya setelah Anda menghubungkan jam dan menekan Start. Tekan Stop untuk mengakhiri pembacaan dan pengiriman.

Data yang digunakan

Server menerima BPM, waktu pembacaan, dan pengenal perangkat acak. Nama pemain dan hash kredensial pairing disimpan untuk menghubungkan perangkat. Kredensial asli disimpan pada jam dan browser pengelola. Cadangan aplikasi jam dinonaktifkan.

Siapa yang dapat melihat?

Siapa pun yang memiliki tautan overlay dapat melihat BPM saat sesi aktif. Jika overlay ditayangkan melalui OBS, penonton siaran juga dapat melihatnya. Tautan dapat diganti dari dashboard untuk mencabut akses tautan lama.

Penyimpanan dan penghapusan

Server tidak menyimpan riwayat BPM ke database. Pembacaan terakhir hanya berada di memori, tidak ditampilkan setelah kedaluwarsa, dan dibuang dalam sekitar 65 detik atau saat sesi berhenti. Pairing yang belum diklaim dihapus setelah sekitar 24 jam. Pilih Hapus pairing di web atau Reset pairing di jam untuk menghapus registrasi perangkat dari database aktif. Penghapusan dari cadangan server mengikuti kebijakan operator saat layanan produksi diluncurkan.

Tentang versi ini

Ini adalah penjelasan perilaku prototipe lokal, belum merupakan kebijakan layanan publik final. Sebelum publikasi, operator layanan harus mencantumkan identitas, kontak privasi, wilayah hosting, serta periode penyimpanan log dan cadangan yang sebenarnya. Tidak ada analitik atau iklan pihak ketiga dalam prototipe ini.
